# Basic Network Sniffer (CodeAlpha Internship Task)

## Objective
Python program to capture and analyze network traffic packets.

## Tools
- Kali Linux, Python 3, Scapy, Wireshark

## How to Run
sudo python3 sniffer.py

## What It Does
Captures live packets and displays:
- Source/Destination IP
- Protocol (TCP/UDP/DNS/ICMP)
- Payload preview
